# Idea

One paragraph: what you want to exist and for whom.

Example: A neighbourhood tool library where people borrow tools instead of buying them, booked from a phone.

# Who it is for

- Renters and new homeowners who need a tool once or twice a year

# First outcomes

Each line becomes a project with a product manager. Write outcomes, not tasks; the managers break them down.

- A landing page that explains the idea and collects interest
- A booking prototype that ten neighbours try
- A written specification of how booking, deposits and returns work, which the neighbours can read and correct

# Constraints

- Budget per month: 50 USD
- Nothing public until the owner says so
