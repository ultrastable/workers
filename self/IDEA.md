# Idea

Ultrastable improves Ultrastable. This organization's only job is to take the specifications in `ultrastable/spec` and make the code in `ultrastable/workers` match them, one reviewed pull request at a time, using the same loops the product sells: managers, staff, a different reviewer for every result, scored predictions, earned autonomy, and a protected improvement budget. It runs on its own Cloudflare account and its own spending caps.

# Who it is for

- The owner, who can say what they want and does not write code
- Anyone evaluating whether Ultrastable can run a real code base on its own

# First outcomes

- Every PLANNED requirement in the specifications becomes BUILT, one reviewed pull request at a time
- The remaining core workers of the reference fleet are replaced by generic modules in core/
- This organization itself is the second installation: it runs the tick, the console and the core modules with no code from the reference fleet
- The first-run walkthrough and needs register work for a person who cannot code
- Every specification, README and status table stays true to the code

# Constraints

- Budget per month: 30 USD
- Agents open pull requests; a person merges until autonomy is earned per surface
- Nothing is made public until the owner says so
- Never use or touch any other Cloudflare account, repository or credential
- Business plans, patents, marketing and outreach are out of scope (SCOPE.md)
